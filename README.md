# Final Project

## Project Name

Final Project

## Description

This project is an AI-powered emotion detection application using the Watson NLP library.

The application analyzes a given text and identifies the scores for five emotions:

- Anger
- Disgust
- Fear
- Joy
- Sadness

It also determines the dominant emotion.

## Technologies Used

- Python
- Flask
- Watson NLP
- Requests
- PyLint
- Unittest

## Project Structure

- `emotion_detection.py` — emotion detection function
- `EmotionDetection/` — Python package
- `server.py` — Flask web application
- `test_emotion_detection.py` — unit tests
- `templates/` — web interface
- `static/` — frontend JavaScript and styling
